# Condux 지원 페이지

[Condux](https://github.com/pgup3017/condux) 앱의 지원 안내와 개인정보 처리방침을 GitHub Pages 로 공개하는 저장소입니다.

- 지원 페이지: https://pgup3017.github.io/condux-site/
- 개인정보 처리방침: https://pgup3017.github.io/condux-site/privacy.html

앱 소스와 업데이트 일지는 Condux 저장소에 있습니다. 이 저장소는 `index.md`, `privacy.md`, `_config.yml` 로만 이루어져 있고, 앱 프로젝트의 `scripts/publish-site.sh` 가 내용을 올립니다.
